POST

/create-order

Create a new payment checkout session and get the payment URL to redirect your customer.

Request Headers

Content-Type: application/json
X-Fam-Key: <YOUR_SECRET_API_KEY>

WEBHOOK

Payment Callbacks

When a payment is successfully completed, we will send a POST request to your `callback_url`.

Security (HMAC Verification)

To verify that the webhook actually came from us, we send a header X-FamGateway-Signature. Generate an HMAC-SHA256 signature of the raw JSON payload using your Secret API Key, and compare it with our header.

# Python Example
import hmac, hashlib
signature = hmac.new(
    api_key.encode(), 
    raw_payload_body, 
    hashlib.sha256
).hexdigest()

if signature == headers.get('X-FamGateway-Signature'):
    print("Valid Webhook!")
