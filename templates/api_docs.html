API Documentation

Secret API Key

Use this key in the header to authenticate your API requests.

Keep this key secret. Do not share it publicly or expose it in client-side code (JS, React, etc).

Base URL

{{ request.host_url.rstrip('/') }}
POST

/api/create-order

Create a new payment checkout session and get the payment URL to redirect your customer.

Request Headers

Content-Type: application/json
X-Fam-Key: <YOUR_SECRET_API_KEY>

Request Body (JSON)

{
  "amount": 499.00, // (Required) Float. Amount in INR
  "order_id": "ORDER_987654", // (Optional) Your internal order ID
  "customer_name": "John Doe", // (Optional) Customer Name
  "customer_email": "john@example.com", // (Optional) Email for automated receipt
  "callback_url": "https://your-site.com/webhook" // (Optional) URL to receive webhooks
}

Success Response

{
  "status": "success",
  "payment_url": "{{ request.host_url.rstrip('/') }}/pay/FAM12345678",
  "txn_id": "FAM12345678"
}

Redirect your user to the `payment_url` to complete the transaction.

WEBHOOK

Payment Callbacks

When a payment is successfully completed, we will send a POST request to your `callback_url`.

Webhook Payload

{
  "status": "success",
  "txn_id": "FAM12345678",
  "merchant_order_id": "ORDER_987654",
  "amount": 499.00,
  "utr": "123456789012"
}

Security (HMAC Verification)

To verify that the webhook actually came from us, we send a header X-FamGateway-Signature. Generate an HMAC-SHA256 signature of the raw JSON payload using your Secret API Key, and compare it with our header.

# Python Example
import hmac, hashlib
signature = hmac.new(
    api_key.encode(), 
    raw_payload_body, 
    hashlib.sha256
).hexdigest()

if signature == headers.get('X-FamGateway-Signature'):
    print("Valid Webhook!")
